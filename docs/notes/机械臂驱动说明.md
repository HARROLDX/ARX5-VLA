## 启动 CAN

### 先直接启动can

```bash
sudo slcand -o -f -s8 /dev/arxcan1 can1
sudo ifconfig can1 up

sudo slcand -o -f -s8 /dev/arxcan2 can2
sudo ifconfig can2 up

sudo slcand -o -f -s8 /dev/arxcan0 can0
sudo ifconfig can0 up

sudo slcand -o -f -s8 /dev/arxcan3 can3
sudo ifconfig can3 up
```

## 单左臂遥操作与末端控制

### 单个机械臂-左臂：

单臂左遥操作：
终端1-从臂

```bash
cd /home/agilex/ARX_X5-main/ARX_X5-main/ROS2/X5_ws
source install/setup.bash
ros2 launch arx_x5_controller open_remote_slave._single.launch.py
```

此 launch 名称按原笔记保留，包含 `slave.`；当前仓库未包含对应单臂 launch，需在外部驱动工作区核对。

上述不但可以遥操作，同样也是机械臂关节控制的驱动

如果使用末端位置姿态控制，

```bash
ros2 launch arx_x5_controller open_single_arm.launch.py
```

但该launch无法被主臂遥操作

终端2-主臂

```bash
cd /home/agilex/ARX_X5-main/ARX_X5-main/ROS2/X5_ws
source install/setup.bash
ros2 launch arx_x5_controller open_remote_master_single.launch.py
```

## 键盘控制与重新编译

### 键盘测试机械臂

```bash
cd /home/agilex/ARX_X5-main/ARX_X5-main/ROS2/X5_ws
source install/setup.bash
ros2 launch arx_x5_controller open_single_arm.launch.py
```

改yaml要重新编译

```bash
cd /home/agilex/ARX_X5-main/ARX_X5-main/ROS2/X5_ws
source install/setup.bash
ros2 run arx_x5_controller KeyBoard
```

KeyBoard -> /arm_cmd -> X5Controller normal 模式 -> can1 单臂

常用按键：

```text
w/s      x 方向前后
a/d      y 方向左右
方向键上/下  z 方向上下
n/m      roll
./l      pitch
,/ /     yaw
o/c      夹爪开/合
i        重力补偿
r        回零
```

### 重新编译

原笔记使用以下清理后重编译流程，会删除当前工作区的 `build/`、`install/`、`log/`。先确认工作目录与待保留产物。

```bash
cd /home/agilex/ARX_X5-main/ARX_X5-main/ROS2/X5_ws

rm -rf build install log
colcon build
```
